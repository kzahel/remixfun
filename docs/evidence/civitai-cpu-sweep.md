# SDXL Base Civitai CPU-RNG candidate sweep on Mac

Date: 2026-09-27. The goal was to find several public Civitai images that
could reuse the verified SDXL Base 1.0 checkpoint on this Apple M4 Pro without
downloading another model or a LoRA, then check decoded-pixel equality against
real Comfy/MPS outputs.

The [Civitai images API](https://github.com/civitai/civitai-developer-docs/blob/main/site/reference/images.md)
was queried read-only for version `126601` with metadata. Approximately 5,000
oldest and 3,000 newest gallery records were screened by cursor. Gallery
association was only a shortlist: each selected image was acquired from its
individual page through Remixfun's provider, and its generation data was
checked for exact checkpoint identity and additional resources. Several
apparently simple `RNG: CPU` gallery results were rejected at that stage
because the page also named a refiner checkpoint. Recent Civitai-hosted
examples in the scanned pages disclosed extra resources or source settings,
and no simple Comfy-native workflow with the same checkpoint was identified.
This was a bounded search, not an exhaustive survey of Civitai.

Four uploaded PNGs had an SDXL Base version `126601` resource, matching model
hash `31e35c80fc`, `RNG: CPU`, Euler ancestral sampling, text-to-image process,
1024 × 1024 dimensions, and no reported LoRA, refiner, ControlNet or hires
stage. They reused local checkpoint SHA-256
`31e35c80fc4829d14f90153f4c74cd59c90b779f6afe05a74cd6120b893f7e5b`;
the pinned Comfy adapter verified its bytes before generation. A single managed
ComfyUI v0.35.0/MPS process ran four sequential experimental graphs. These
were direct Comfy adapter experiments, **not** submissions through Remixfun's
imported-attempt API: the current profile blocks the reported `RNG` field, and
three sources omit a negative-prompt field.

All trials assumed Comfy's `normal` scheduler because the sources omitted a
scheduler. Image 1785120 explicitly reported CLIP skip 2 and a negative prompt.
For the other three, the saved A1111-style PNG infotext had no negative-prompt
line; the experiments assumed an empty negative prompt and CLIP layer -2.
The source PNGs retain `parameters` metadata, but their bytes are still treated
as provider references rather than independently verified originals. All
comparisons decoded RGBA without resizing. RGB errors are on a 0–255 scale,
not perceptual similarity scores.

None matched the saved source pixels. The lowest error score belongs to an
assumption-heavy trial and does not identify a correct source workflow. CPU
seeded noise alone does not prove numerical equivalence between the source
generator and this Comfy/MPS profile. A better next oracle would retain the
original graph and RNG implementation, or use a controlled image generated by
the same pinned Comfy profile before attempting a public cross-backend match.

These failures are **exact-pixel** failures, not failures to generate the
requested subjects. A focused visual check of 1785120 found a wooden cabin,
lake and volcano in both images, with different positions and details. Image
2027882 likewise showed a sleeping doll among clouds in both images, with a
different pose and composition. Dreamtime's old import flow used “Remix” for a
generator handoff; the checked-in code and tests do not establish pixel-equal
reconstruction of a foreign source. That distinction matters when comparing
these results with remembered Dreamtime behavior. Its SDXL generation path
also inserts a default negative prompt when the imported value is empty,
which can produce a useful remix while changing the source recipe.

An additional controlled graph check on 1785120 removed Remixfun's explicit
`CLIPSetLastLayer(-2)` node and used Comfy's native SDXL CLIP default, as in
Dreamtime's simple SDXL template. The output was pixel-identical to the
explicit-layer attempt and still differed from the Civitai source. This rules
out that one graph difference as the cause for this fixture; it does not rule
out other text encoding, sampler, VAE or backend differences. Raw output and
comparison are under `artifacts/civitai-cpu-sweep/clip-default/`.

Ignored raw inputs, outputs, workflows, source hashes and full metrics are in
`artifacts/civitai-cpu-sweep/`. No image, checkpoint, runtime environment or
machine-local path was committed.
